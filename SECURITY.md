# Security Policy

KnowYi Technologies Inc. takes security issues affecting its public software, websites and customer-facing systems seriously.

If you believe you have found a security vulnerability in a KnowYi-controlled system, please do not disclose it publicly before giving the company a reasonable opportunity to investigate.

Report security issues to:

**contact@knowyi.tech**

Please include:

- the affected URL, repository or system,
- a concise description of the issue,
- steps to reproduce where possible,
- and any evidence needed to understand the impact.

Do not include customer confidential information or third-party credentials in a public GitHub issue.

KnowYi will review good-faith reports and determine the appropriate response based on severity and scope.
